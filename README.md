# Bugu Cup XI - Prototype

Prototipo navigabile senza backend, realizzato per validare il tono e il flusso dell'esperienza.

## Avvio locale

Nella cartella del progetto:

```powershell
python -m http.server 4173
```

Quindi apri `http://localhost:4173`.

## Incluso

- Home immersiva con hero, punteggio storico, programma e gallery.
- Iscrizione demo in 6 schermate, una domanda per volta.
- Dashboard admin dimostrativa dal link "Apri dashboard demo".

I dati e le immagini sono temporanei: il prossimo passaggio sara sostituirli con contenuti reali e migrare l'interfaccia a Next.js + Supabase.
